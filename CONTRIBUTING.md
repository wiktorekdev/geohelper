# Contributing

GeoHelper is a side project, so keep it simple.

## Setup

```bash
bun install
bun run dev
```

Need Node 20+, Rust, Bun. Linux requires GTK 3 + WebKitGTK 4.1.

## Where to start

Check [Issues](https://github.com/wiktorekdev/geohelper/issues). If you have an idea, open an issue first.

## PRs

1. Fork and branch from `main`
2. Make changes, run `bun run build`
3. Keep it focused
4. Open PR with description

No tests required.

## Commits

Use conventional commit prefixes:
```
feat: add feature
fix: fix bug
chore: maintenance
```

## Style

Run `bun run format` before committing. TypeScript strict mode is on.

## Releases

I handle releases. Don't bump versions.
